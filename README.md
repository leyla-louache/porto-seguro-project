# Porto Seguro — Safe Driver Prediction

Machine Learning project for the course  
Scientific Programming and Data Analysis / Advanced Data Analytics.

## Project structure

- `Notebooks/`: exploratory data analysis and machine learning notebooks
- `data/`: local dataset and generated split indices

## Dataset preparation

The dataset is not stored in this GitHub repository.

Each group member must first execute:

`Notebooks/00_download_split_eda.ipynb`

This notebook downloads the dataset from OpenML and stores it locally in the
`data/` directory.

## Workflow

1. Clone the repository.
2. Install the required dependencies.
3. Execute `Notebooks/00_download_split_eda.ipynb`.
4. Execute the assigned modelling notebook.
